# 要点
- 商业模式，护城河
- 商业道德，价值观，领导人气质
- 股市周期，大环境
- 机会合适，股价低

# 估值方法
| 方法           | 特点       | 适用对象    |
| ------------ | -------- | ------- |
| DCF          | 严谨，数据要求高 | 成熟现金流企业 |
| DDM          | 简单，依赖股息  | 高分红公司   |
| PE / PB / PS | 简便直观     | 普通投资者常用 |
| EV/EBITDA    | 运营效率分析好  | 盈利成熟公司  |
| SOTP         | 分业务估值    | 多元化公司   |
| PEG          | 成长性 + PE | 增长股     |

# 企业阶段
| 阶段     | 主要特征            | 经营重点            | 财务特征             |
| ------ | --------------- | --------------- | ---------------- |
| 1. 创业期 | 刚成立，产品开发和市场探索   | 产品研发，市场验证，寻找客户  | 通常亏损，现金流紧张，融资频繁  |
| 2. 成长期 | 市场认可，销售快速增长     | 扩大市场份额，提升生产能力   | 收入快速增长，亏损逐渐减少    |
| 3. 成熟期 | 业务稳定，增长趋缓       | 优化运营效率，维护客户关系   | 收入增长放缓，利润稳定或增长缓慢 |
| 4. 衰退期 | 市场饱和或替代品出现，业务下滑 | 转型升级或控制成本，寻找新机会 | 收入下降，利润减少，可能亏损   |
| 5. 转型期 | 重新定义业务模式或进入新市场  | 创新驱动，战略调整，业务重塑  | 视具体转型成效，收入和利润波动大 |
